## ✨ Highlights

- 🎨 **Dark teal & white palette** (`#115e59`) — clean, professional medical aesthetic
- 🕸️ **Real-time animated background** — Delaunay-style triangulated lattice on a full-viewport canvas, with cursor-field deformation and vertex energy pulses
- ⚡ **Zero dependencies** — plain HTML, CSS & JavaScript. No build step, no framework
- 📱 **Fully responsive** — adaptive layouts and reduced vertex density on small screens
- ♿ **Accessibility-first** — respects `prefers-reduced-motion` with a static frame fallback
- 🖨️ **Print-friendly** — canvas background hidden entirely when printing
- 🔋 **Performance-aware** — animation pauses automatically when the tab is hidden

## 🚀 Running Locally

No install required. Open `index.html` directly, or serve it:

```bash
python3 -m http.server 5173
# → visit http://127.0.0.1:5173
```

---

## ☁️ Deployment

Hosted on **[Vercel](https://vercel.com)** as a static site — no build command, no output directory.

The GitHub repo is connected, so **every push to `main` deploys automatically**:

```bash
git add -A
git commit -m "your message"
git push          # Vercel builds & goes live in ~30s
```
